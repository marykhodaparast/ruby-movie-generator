# Movie Gallery — Ruby Task 5

A Rails application that generates movie data using a configurable seed and locale. It provides a paginated movie table and a movie gallery with dynamically loaded cards.

## Features

- Deterministic movie data generation using a configurable seed.
- Locale selection for generating region-specific movie data.
- Configurable average likes and review count.
- Movie information including title, actors, year, genre, likes, and reviews.
- Paginated movie table.
- Movie gallery with an infinite-scroll implementation.
- Responsive gallery cards with illustrative images.

## Requirements

- Ruby 3.2 or newer, compatible with the project's Rails version.
- Bundler.
- SQLite3, as configured by the Rails application.

## Setup

Clone the repository and enter the project directory:

```bash
git clone YOUR_REPOSITORY_URL
cd YOUR_PROJECT_DIRECTORY
```

Replace the placeholders with the actual Git repository URL and project directory name.

Install the Ruby dependencies:

```bash
bundle install
```

## Run the application

Start the Rails development server:

```bash
bin/rails server
```

Open the following address in your browser:

http://localhost:3000

To stop the server, press `Ctrl + C` in the terminal where it is running.

## Run tests

Run the Rails test suite:

```bash
bin/rails test
```

Check the available routes:

```bash
bin/rails routes
```

## Main routes

- `/` — Main movie page with controls and the paginated table.
- `/movies/gallery` — Gallery endpoint used to load additional movie cards.

## Movie generation controls

The application accepts the following query parameters:

| Parameter | Purpose |
|---|---|
| `locale` | Selects the locale used for generated movie data. |
| `seed` | Controls reproducible movie generation. |
| `likes` | Configures the average likes value. |
| `reviews` | Configures the number of reviews. |
| `page` | Selects the table page or gallery batch. |

Example URL:

```text
http://localhost:3000/?locale=en-US&seed=123456789&likes=5&reviews=3
```

Changing the seed should change the generated dataset. Reusing the same seed and settings should reproduce the same data.

## Data and storage

Movie data is generated by the application and is not stored as individual movie records in the database.

The movie generator is located in:

```text
app/services/movie_generator.rb
```

Movie data configuration is located in:

```text
config/movie_data.yml
```

The application uses SQLite as configured in `config/database.yml`.
